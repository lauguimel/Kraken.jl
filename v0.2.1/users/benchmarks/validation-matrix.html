Validation matrix ​

The single summary of where each public Kraken module stands against an external reference. Every numeric cell is the headline metric of the linked benchmark page — no value is reproduced here that is not on one of those pages. Each row gives the published/analytical reference, an independent other-solver comparison where one exists, and the tolerance met against the mandate §3 acceptance bar.

Where RheoTool covers a case it is the literal reference solver; where it does not, §3's escape clause anchors the row to the canonical published data set (Ghia 1982 for the cavity, de Vahl Davis 1983 for thermal, Clift et al. 1978 for sphere drag), each with an independent OpenFOAM cross-check where available.

Notes ​

  • Follow the artifact link for the full error-norm tables, methodology, mesh/backend details and caveats — the matrix carries only the headline metric.

  • 3D rows carry larger residuals and are documented as resolution-limited on their pages (sphere drag +8.9 %). 3D natural convection is wired (natural_convection_3d preset) but only smoke-validated; a quantitative 3D thermal benchmark is a future item. The 2D rows are the strict acceptance gates.

  • AMR conservation ≠ AMR accuracy. Mass conservation is exact to roundoff across all shipped CSVs. Integrated-quantity accuracy is not yet a passing gate: the cylinder C_d gap vs the dense-leaf oracle is small only when the coarse/fine interface is buffered off the boundary layer (~1.06×, interface-buffered CSV), and is large for a compact patch cutting the near-wall region (≈3.2–5.6×, the shipped …_conv_* CSVs). This near-interface transport gap is the open item motivating the subcycling integration tracked for the next release. Separately, a bit-exact full-domain refined-patch ↔ dense-leaf parity (L2 = L∞ < 1e-14) is demonstrated for the 3D Poiseuille route-native canary (test/test_conservative_tree_streaming_3d.jl), establishing that the refined path reproduces the leaf solution when the whole domain is refined; it is not a 2D-cylinder accuracy result.

  • Literal reference-solver backfill. The Newtonian cavity row ships a complete benchmarks/results/rheotool_compare/newtonian/ bundle (both-solver CSVs, per-Re error norms, the .krk, and a self-contained plot.py). The thermal and viscoelastic literal bundles are the next legs of the same backfill.
