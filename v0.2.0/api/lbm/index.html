LBM API

The LBM API documents the core lattice traits, equilibrium helpers, collision and streaming wrappers, macroscopic reconstruction, forcing, MRT/TRT variants, and runtime kernel-building utilities.

Kraken.AbstractLattice — Type
AbstractLattice{D, Q}

Abstract type for LBM lattice models parameterized by spatial dimension D and number of discrete velocities Q.

Kraken.cs2 — Method
cs2(::AbstractLattice) -> Float64

Speed of sound squared (1/3 for standard lattices).

Kraken.equilibrium — Function
equilibrium(lattice, ρ, u, q) -> Float64

Compute equilibrium distribution for direction q given density ρ and velocity vector u.

f_eq = w_q · ρ · (1 + (c_q · u)/cs² + (c_q · u)²/(2·cs⁴) - u·u/(2·cs²))
Kraken.lattice_dim — Method
lattice_dim(::AbstractLattice{D}) -> Int

Return spatial dimension of the lattice.

Kraken.lattice_q — Method
lattice_q(::AbstractLattice{D,Q}) -> Int

Return number of discrete velocities.

Kraken.opposite — Function
opposite(lattice) -> SVector{Q, Int32}

Return index of the opposite direction for each velocity.

Kraken.velocities — Function
velocities(lattice) -> SMatrix{D, Q, Int32}

Return discrete velocity vectors as columns of a static matrix.

Kraken.weights — Function
weights(lattice) -> SVector{Q, Float64}

Return quadrature weights for the lattice.

Kraken.D2Q9 — Type
D2Q9 <: AbstractLattice{2, 9}

Standard 2D lattice with 9 discrete velocities.

Velocity ordering: 0: ( 0, 0) — rest 1: ( 1, 0) — east 2: ( 0, 1) — north 3: (-1, 0) — west 4: ( 0,-1) — south 5: ( 1, 1) — NE 6: (-1, 1) — NW 7: (-1,-1) — SW 8: ( 1,-1) — SE

Kraken.D3Q19 — Type
D3Q19 <: AbstractLattice{3, 19}

Standard 3D lattice with 19 discrete velocities.

Velocity ordering: 0: ( 0, 0, 0) — rest 1–6: axis-aligned (±x, ±y, ±z) 7–18: edge-aligned (±x±y, ±x±z, ±y±z)

Kraken.compute_macroscopic_pressure_2d! — Method
compute_macroscopic_pressure_2d!(p, ux, uy, f, C, Fx, Fy; ρ_l=1.0, ρ_g=0.001)

Pressure-based macroscopic computation for two-phase flows (He-Chen-Zhang model).

  • p: pressure field (p = cs²·Σf)
  • ux, uy: velocity (momentum / ρ(C), with half-force correction)
  • C: VOF field (liquid fraction)
  • Fx, Fy: total body force (surface tension + axisym correction + gravity)
  • ρ_l, ρ_g: physical densities of liquid and gas
Kraken.collide_mrt_2d! — Method
collide_mrt_2d!(f, is_solid, ν; s_e=1.4, s_eps=1.4, s_q=1.2)

MRT collision for D2Q9 (Lallemand & Luo, 2000). The stress relaxation rate sν = 1/(3ν + 0.5) is computed from viscosity. Other rates (se, seps, sq) can be tuned for stability (default values from literature).

Kraken.collide_twophase_mrt_2d! — Method
collide_twophase_mrt_2d!(f, C, Fx_st, Fy_st, is_solid; ρ_l, ρ_g, ν_l, ν_g, s_e, s_eps, s_q)

Two-phase MRT collision for D2Q9 with per-node viscosity from VOF field C and Guo forcing (surface tension + body forces).

Variable viscosity: ν(C) = C·νl + (1-C)·νg → sν = 1/(3ν(C) + 0.5) Stability relaxation rates: se, seps, sq (defaults from Lallemand & Luo, 2000).
